# Ôn Tập Triết 🎓

Ứng dụng web ôn thi trắc nghiệm đại học phong cách A4 tối giản, nhẹ và không phân tâm.

🔗 **Link web:** [ontaptriet.vercel.app](https://ontaptriet.vercel.app/)

## Điểm nhấn
- **2 Chế độ:** Giấy A4 (trắng tinh khiết, tắt hình nền tiết kiệm pin) & Tối (hỗ trợ Live Wallpaper chill đêm).
- **Tuần tự 15 Live Wallpaper:** Tự động đổi video sau mỗi lần tải trang, không trùng lặp.
- **7 Phông chữ Serif:** Chuẩn tiếng Việt (Times New Roman, Lora, Merriweather, Garamond...).
- **Tiện ích thi:** Random cả đề / Ôn theo phạm vi, 1-click copy câu hỏi sạch đẹp dán vào AI, lưu lịch sử bài làm.
- **Easter Eggs bí mật:** Một vài bất ngờ thú vị ẩn giấu ngẫu nhiên khi dùng web.
